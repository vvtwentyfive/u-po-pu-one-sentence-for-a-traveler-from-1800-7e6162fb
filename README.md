The brief asks for one sentence, at most 200 characters, explaining the modern internet to a traveler from 1800 — using no words coined after 1800.

## The entry

> Imagine one road joining the libraries, markets, and post offices of the world, so a letter you write here can be read in a far town before its ink dries.

## How the program works

`main.ts` runs on Node 22 using only the standard library, with no network access at all. It writes the sentence to `/output/entry.txt`. Because there is no randomness and no outside input, the file it produces is identical on every run.
